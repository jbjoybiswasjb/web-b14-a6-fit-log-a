# FitLog - Workout Library

FitLog is a workout library web application where users can explore workouts, view workout details, create a personal workout plan, and save workouts for later.

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- React
- React Toastify
- REST API

## Key Features

1. **Workout Library**  
   Browse workouts with information such as category, equipment, duration, calories, and rating.

2. **Workout Details**  
   View detailed information, specifications, and step-by-step instructions for each workout.

3. **Today's Plan**  
   Add workouts to a personal workout plan and manage today's exercises.

4. **Save Workouts**  
   Save workouts for later and access them from the Saved section.

5. **Responsive Design**  
   The application works smoothly on desktop, tablet, and mobile devices.
